# 兰台桌面壳（lantai-shell）

把「运行 `lantai.exe` → 浏览器打开 `http://127.0.0.1:8000/`」的用法，收敛成一个轻量桌面客户端：启动后自动拉起兰台服务（无独立 cmd 窗口）、就绪后直接显示兰台 Web UI，看起来是一个完整的单机应用。

## 快速开始（绿色便携版）

1. 解压 `release/lantai-shell-0.1.19-windows-x64.zip` 到任意目录（如 `D:\tools\lantai`）；
2. 双击 `lantai-shell.exe` 启动——壳在内部自动拉起兰台服务，就绪后显示主界面；
3. 关闭窗口即退出应用并结束服务（默认行为，可在设置中改为"退出后保持服务运行"）。

> 首次启动会创建 `data/` 目录（数据库、上传文件、日志），与直接运行 `lantai.exe` 的数据目录结构一致。

## 功能

| 功能 | 说明 |
|---|---|
| 一键启动 | ConPTY 终端无窗口自动执行 `lantai.exe --server`（服务就绪前启动画面实时显示启动日志） |
| 主界面 | iframe 内嵌 `http://127.0.0.1:8000/` 兰台 Web UI（问答应答、文档管理、配置） |
| 终端浮层 | 右下角「终端」按钮呼出/收起；可查看服务日志、手动输入命令、`⟳` 重启 / `⏹` 停止服务 |
| 缩放 | 终端面板 `−/＋/100%` 按钮或 `Ctrl+=/-/0` 快捷键，50%–300%，重启保留 |
| 设置 | `⚙`：启动命令、工作目录、端口、就绪超时、退出保持运行、崩溃自动重启 |
| 单实例 | 重复启动只唤起已有窗口 |
| 便携模式 | 程序目录含 `portable.marker` 时，`settings.json` 与配置存程序目录，随目录走 |

## 数据与配置位置

| 项 | 位置 |
|---|---|
| 壳配置 | 便携模式：程序目录 `settings.json`；标准运行：`%APPDATA%\com.lantai.app\settings.json` |
| 兰台数据 | 与 `lantai.exe` 同目录的 `data/`（rag.db、uploads、logs） |

## 直接运行服务（不使用壳）

`release/lantai-0.1.19-windows-x64/lantai.exe`——原有控制台模式，自动打开浏览器；`--server` 参数不自动打开浏览器（供壳使用）。
