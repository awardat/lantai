# 兰台桌面壳（lantai-shell）方案

> 状态：**已实施完成（2026-08-24，兰台 0.1.19）**
> 目标：把「运行 `lantai.exe` → 浏览器打开 `http://127.0.0.1:8000/`」的用法，收敛成一个轻量桌面客户端：启动后自动拉起兰台服务（无独立 cmd 窗口）、就绪后内嵌显示兰台 Web UI，看起来是一个完整的单机应用。
> 来源：复用 `C:\code\dsh-ui`（DeepSeek Harness 桌面壳，Tauri 2）工程改造，业务逻辑（兰台 FastAPI 后端 + 原生前端）架构不变。

## 实施记录

- 框架：Tauri 2（tauri 2.11.5）+ WebView2（Win10/11 内置），GNU 工具链（mingw64，本机无 MSVC）
- 复用自 dsh-ui 并保留：ConPTY 终端（portable-pty，无独立 cmd 窗口）、自动启动命令、HTTP 就绪探测/快速失败、终端面板呼出收起、缩放（按钮/Ctrl±0/持久化）、Job Object 退出清理、keep-alive、单实例、auto_restart、设置页、便携模式（portable.marker）
- **架构定案**：单窗口 + iframe（Windows 第二个 WebView2 窗口合成不可用）；iframe 为 OOPIF 独立 CDP target
- **兰台化改造**：
  - 启动命令默认 `lantai.exe --server`（兰台 `run.py` 新增 `--server` 参数：不自动开浏览器）
  - 就绪探测端口 8000（`http://127.0.0.1:8000/`）
  - 工作目录：设置留空 = 壳程序所在目录（兰台冻结模式数据目录基于 exe 位置，与 cwd 无关）
  - 删除 dsh 专属逻辑：dsh 可用性检测/首次下载提示/会话 workspace 跟随（`decode_project_key`/`find_last_workspace`/`needs_download`）；代理设置 UI 移除（兰台无联网下载场景，Rust 配置字段保留兼容旧 settings.json）
  - 品牌：产品名 `lantai_shell`、identifier `com.lantai.app`、窗口标题「兰台」、图标（PIL 生成「兰」字藏青渐变圆角方块，scripts/gen_shell_icon.py）
  - 发布形态：**绿色便携目录**（不建 setup，沿用兰台发布规则）：壳 exe + WebView2Loader.dll + portable.marker + 兰台服务 one-dir 内容
- 直接运行 `release/lantai-0.1.19-windows-x64/lantai.exe` 保持原有控制台模式（自动开浏览器）
- 产物：`release/lantai-shell-0.1.19-windows-x64/`（+ zip）
- 用户使用见 README.md；开发/构建/调试见 DEVELOPMENT.md

## 1. 背景与现状

当前用法：运行 `lantai.exe`（或源码 `python run.py`）→ 自动打开浏览器访问 `http://127.0.0.1:8000/`。控制台窗口常驻，交互生硬；希望收敛为单机应用形态。

### 已核实的关键事实

| 事实 | 说明 |
|---|---|
| 启动命令 | `lantai.exe --server`（PyInstaller one-dir 冻结版；源码为 `python run.py --server`） |
| 进程形态 | 前台阻塞式 uvicorn 进程，杀掉即停服 |
| 端口 | 默认 `127.0.0.1:8000`（config.DEFAULT_PORT） |
| 工作目录 | **与 cwd 无关**：冻结模式 BASE_DIR = exe 所在目录，data/ 落 exe 同目录 |
| 就绪判定 | HTTP GET `http://127.0.0.1:8000/` 返回 200（比解析终端文本可靠） |
| 交互需求 | 无（uvicorn 无交互提示） |

## 2. 技术选型

| 方案 | 结论 |
|---|---|
| **Tauri 2（复用 dsh-ui）** | ✅ 已实施：轻量（数 MB）、WebView2 系统内置、单窗口 + iframe 方案在 dsh-ui 已充分验证 |
| Electron | 备选（重、内存高），dsh-ui 已否决 |
| pywebview | 不推荐（缩放/终端需绕 WebView2 COM） |

## 3. 总体架构

```
┌───────────────────────────── Windows ─────────────────────────────┐
│  ┌── Tauri 主进程 (Rust) ──────────────────────────────────────┐  │
│  │  terminal.rs   ConPTY 终端（portable-pty + cmd.exe）        │  │
│  │  server.rs     生命周期状态机：就绪探测 / 重启 / 停止 /      │  │
│  │                 keep-alive / 退出清理（按端口杀兜底）        │  │
│  │  zoom.rs       缩放（50–300%，持久化）                      │  │
│  │  job.rs        Windows Job Object（KILL_ON_JOB_CLOSE）      │  │
│  │  download.rs   WebView2 下载支持                            │  │
│  └──────────────────────────────────────────────────────────────┘  │
│  ┌── 主窗口（1280×738，标题「兰台」）───────────────────────────┐   │
│  │  shell 页（tauri 本地资产）→ iframe 内嵌 http://127.0.0.1:8000/ │
│  │  （就绪前显示启动遮罩：logo + 状态 + 内嵌只读终端）           │   │
│  └──────────────────────────────────────────────────────────────┘   │
│  cmd.exe（ConPTY，无窗口）── 自动喂入 `lantai.exe --server`         │
└─────────────────────────────────────────────────────────────────────┘
```

### 启动流程状态机

```
[启动] ──▶ BOOT（启动遮罩 + 自动执行 lantai.exe --server）
            （后台 500ms 轮询 HTTP 8000；若端口已监听 → 直接连接）
              │  HTTP 200 就绪（默认超时 120s）
              ▼
[READY] ◀─── iframe 加载 http://127.0.0.1:8000/；终端收起为右下角按钮
              │  点击按钮 → 终端面板展开（日志 / 手动输入 / ⟳重启 / ⏹停止）
              ▼
[FAILED/STOPPED] ── 按钮红/灰 + 提示；「重新启动」
```

退出应用：默认 Job Object 整树终止（cmd → lantai.exe → uvicorn）；设置「退出后保持服务运行」时关闭弹询问框（保持运行=脱离进程 / 结束服务=按端口杀）。

## 4. 功能设计要点

- **无独立 cmd 窗口**：ConPTY（portable-pty，wezterm 同款）承载 cmd.exe 会话，窗口不可见，输出经 IPC 到前端 xterm.js 渲染
- **就绪双通道**：HTTP 探测为主；终端输出扫失败特征（`eaddrinuse`、`is not recognized` 等）快速失败
- **端口占用**：TCP 有监听即直连（不区分占用者）
- **配置项**（`settings.json`）：startup_command（默认 `lantai.exe --server`）、working_dir（默认空=壳目录）、port（8000）、ready_timeout_sec（120）、zoom、auto_start、keep_alive_on_exit（默认 false）、auto_restart、terminal_height_ratio

## 6. 构建与发布

```powershell
# 前端
cd shell && npm run build:ui          # → ui/dist
# Rust（复用 dsh-ui 编译缓存，首次约 2-5 分钟）
$env:CARGO_TARGET_DIR='C:\code\dsh-ui\src-tauri\target'
$env:PATH="C:\code\dsh-ui\.tools\mingw64\bin;$env:PATH"
cd shell/src-tauri && cargo build --release
# 产物
shell/src-tauri/target/release/lantai-shell.exe
# 组装绿色便携目录（壳 exe + WebView2Loader.dll + portable.marker + 服务 one-dir 内容）
# → release/lantai-shell-0.1.19-windows-x64/ + zip
```

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| Windows 第二 WebView2 窗口合成不可用 | 单窗口 + iframe（dsh-ui 已验证） |
| GNU 链接警告 `.rsrc merge failure` | 无害，可忽略 |
| 8000 端口被外部进程占用 | 直连 + 终端提示；设置页可换端口 |
| WebView2 缺失（罕见） | 系统内置，Win10/11 无感 |
