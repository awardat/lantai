## 一、数据库与存储

**首选：PostgreSQL + pgvector**——企业增量成本最低（复用现有 DBA/运维/备份/权限体系），关系数据（文档元数据/用户/RBAC/对话历史）与向量同库、事务一致；HNSW/IVFFlat 索引支撑百万~千万级向量。

**备选**：

| 方案 | 适用 |
|------|------|
| **Qdrant** | 规模中等、要混合检索（内置 BM25 稀疏向量，契合 R107）且部署简单 |
| **Milvus** | 超大规模 / GPU 索引（十亿级向量） |
| **OpenSearch / ES** | 已有 ES 基础设施的企业复用（dense vector + BM25） |

**企业落地配套**：元数据过滤（文档/时间/权限）、混合检索融合、高可用备份、鉴权审计；兰台 `VectorStore` 抽象（R108）为唯一存储入口，替换 = 新实现 + 配置项，业务代码不感知。

## 二、后端架构（企业级）

| 域 | 现状 | 企业级建议 |
|----|------|-----------|
| 应用框架 | FastAPI（异步、类型安全、自动 OpenAPI） | **保持 FastAPI**——生态成熟，继续沿用 |
| 服务形态 | 单体 + 模块化 | 初期保持单体（模块边界清晰：解析/检索/问答/管理）；规模后按需拆分独立服务 |
| 异步任务 | BackgroundTasks 线程池（解析/OCR） | **任务队列**：Celery / ARQ + Redis（持久化任务、重试、分布式 worker） |
| 缓存与会话 | 内存会话表 | **Redis**：会话、检索缓存、限流计数、发布订阅 |
| 数据访问 | 原生 sqlite3 | SQLAlchemy(async) + Alembic 迁移 + pgvector |
| 鉴权授权 | 单管理员密码门禁 + API token | **RBAC（R101）+ JWT/OIDC（Keycloak）**；API 网关统一鉴权 |
| 密钥管理 | XOR 封装（演示级） | **Vault / 云 KMS** + AES-GCM；密钥轮换 |
| 日志审计 | lantai-*.log + agent-*.log（本地文件） | 结构化日志 + 集中采集（ELK / Loki）；智能体日志对接审计与合规留痕（R114） |
| 监控告警 | 无 | **Prometheus + Grafana**：请求量/延迟/错误率/AI 调用成本/模型耗时 |
| 限流防滥用 | 密码失败锁定 | 网关级限流（令牌桶）+ AI 调用配额 |
| 外部调用 | 直接 httpx 调 AI | **AI 网关层**：统一协议、模型路由、成本统计、失败重试/降级 |

## 三、前端架构（企业级）

| 域 | 现状 | 企业级建议 |
|----|------|-----------|
| 技术栈 | 原生 HTML/CSS/JS（无构建） | **Vue 3 + TypeScript + Vite**（组件化、类型安全、可测试）；UI 库 Element Plus / Ant Design |
| 状态管理 | 全局变量 | **Pinia**（会话、配置、文档状态） |
| 路由 | Tab 切换 | **vue-router**（业务/配置分区、路由守卫接鉴权） |
| API 层 | fetch 封装 | **axios + 统一拦截器**（token 刷新、错误 toast、超时重试） |
| 构建发布 | 无构建 | **CI/CD**（GitHub Actions/GitLab CI）→ npm 制品 → Nginx/CDN 静态托管 |
| 监控 | 无 | **Sentry** 前端错误上报 |
| 国际化 | 中文 | **i18n**（中文/英文） |
| 安全 | onclick 内联（依赖后端净化） | **data-\* 事件委托**纵深防御、CSP、输入校验 |
| 流式渲染 | fetch + ReadableStream | 保持（SSE），封装为可复用 composable |

## 四、技术框架全景（推荐栈）

| 层 | 推荐 | 说明 |
|----|------|------|
| 后端 | FastAPI + SQLAlchemy(async) + Alembic + Celery/ARQ + Redis | 当前 FastAPI 延续 |
| 前端 | Vue 3 + TypeScript + Vite + Pinia + Element Plus | 替代原生单页 |
| 数据库 | PostgreSQL + pgvector | 首选；备选 Qdrant/Milvus |
| 检索 | pgvector HNSW（或 Qdrant sparse）+ 融合排序 | rerank（R106）、hybrid（R107） |
| AI 接入 | OpenAI 兼容统一层（现状 llm.py 扩展为网关） | 模型路由/成本/降级 |
| 可观测 | Prometheus + Grafana + Loki/ELK + Sentry | 指标/日志/前端错误 |
| 部署 | Docker Compose（单机企业）→ K8s（规模化） | R103；Nginx 网关 |
| 安全 | Keycloak/OIDC + RBAC + Vault/KMS + 审计 | R101/R113/R114 |
| 文档规范 | 现有 docs 体系延续 | 需求/方案/版本/变更/评审 |
