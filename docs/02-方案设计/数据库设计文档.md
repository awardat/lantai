## 一、设计约定

- 字符集：UTF-8（读写显式指定，规避 Windows GBK）。
- 主键：自增 INTEGER；时间：ISO8601 字符串（本地时区）。
- 向量存储：`embedding` 列存 float32 小端字节（numpy `tobytes()`），读取时 `np.frombuffer(..., dtype=np.float32)`；维度由配置的 embedding 模型决定（如 bge-m3=1024）。
- 检索：全表扫描 + numpy 余弦（演示规模几十~几百切片，毫秒级）；`VectorStore` 抽象为唯一存储入口，替换向量库（ChromaDB/Milvus，R108）只需新实现该接口。

## 二、表结构

### 2.1 documents（文档记录）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK 自增 | 文档 ID（同时是 uploads 目录名） |
| name | TEXT | NOT NULL | 展示名称（净化后的原始文件名） |
| category | TEXT | NOT NULL | 分类：`text` 文字文档 / `office` Office / `pdf_text` 文字 PDF / `image` 图片 / `pdf_image` 图片 PDF |
| ext | TEXT | NOT NULL | 扩展名（小写） |
| size | INTEGER | NOT NULL | 文件字节数 |
| status | TEXT | NOT NULL | `parsing` 解析中 / `ready` 已就绪 / `failed` 失败 |
| error | TEXT | 可空 | 失败原因（中文，含解决建议） |
| chunk_count | INTEGER | 默认 0 | 切片数 |
| created_at | TEXT | NOT NULL | 上传时间 |

### 2.2 chunks（文本切片）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK 自增 | 切片 ID |
| document_id | INTEGER | NOT NULL, FK→documents.id, 索引 | 所属文档 |
| seq | INTEGER | NOT NULL | 文档内序号（0 起） |
| text | TEXT | NOT NULL | 切片文本（图片类为视觉模型生成的描述/OCR 文本） |
| char_count | INTEGER | NOT NULL | 字符数 |
| embedding | BLOB | NOT NULL | float32 向量字节（维度见配置） |

### 2.3 settings（配置键值）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| key | TEXT | PK | 配置键（见下表） |
| value | TEXT | NOT NULL | 配置值（JSON 或哈希） |

**键定义**：

| key | 值内容 | 说明 |
|-----|--------|------|
| `admin_password_hash` | `pbkdf2$<iterations>$<salt_hex>$<hash_hex>` | 配置密码哈希（PBKDF2-HMAC-SHA256，100k 迭代） |
| `ai_config` | JSON | 七组 AI 配置：`text/office/pdf_text/image/pdf_image/chat/embedding`，每组 `{provider, base_url, api_key(加密), model, prompt, temperature}` |
| `session_secret` | hex | 会话签名密钥 + API Key 存储加密的派生密钥（启动时若缺失自动生成） |
| `app_version` | TEXT | 首次启动写入的版本号（0.1.2），供迁移判断；后续每次启动更新为当前 APP_VERSION |

> 安全说明（首版）：API Key 使用 XOR + base64 封装（密钥由 `session_secret` 经 SHA-256 派生），防止明文落盘，属于演示级防护；接口返回一律脱敏（仅尾 4 位）。升级至 RBAC（R101）时替换为成熟密钥管理（AES-GCM + KMS 等）。

### 2.4 api_tokens（API token）
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK 自增 | token 记录 ID |
| name | TEXT | NOT NULL | 名称（用户命名，如"演示脚本"） |
| token_hash | TEXT | NOT NULL | SHA-256 哈希（明文仅生成时展示一次） |
| prefix | TEXT | NOT NULL | 前缀 `lt-<8位>`（列表展示用） |
| created_at | TEXT | NOT NULL | 创建时间 |
| last_used_at | TEXT | 可空 | 最后使用时间 |
| revoked | INTEGER | 默认 0 | 吊销标记（1=吊销） |

### 2.5 conversations / messages（对话历史，0.1.5 新增，schema v2）

**conversations（会话）**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK 自增 | 会话 ID |
| title | TEXT | 默认"新对话" | 会话标题 |
| created_at | TEXT | NOT NULL | 创建时间 |
| updated_at | TEXT | NOT NULL | 最后消息时间（列表排序） |

**messages（消息）**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK 自增 | 消息 ID |
| conversation_id | INTEGER | NOT NULL, FK→conversations.id, 索引 | 所属会话 |
| role | TEXT | NOT NULL | `user` / `assistant` |
| content | TEXT | NOT NULL | 消息内容 |
| created_at | TEXT | NOT NULL | 发送时间 |

> schema 版本：`PRAGMA user_version = 2`（0.1.5 起）；旧库启动时自动补建新表。

## 三、索引

| 索引 | 表 | 说明 |
|------|-----|------|
| idx_chunks_document | chunks(document_id) | 删除文档级联、按文档查切片 |
| idx_docs_status | documents(status) | 解析状态筛选（列表页） |
| idx_tokens_revoked | api_tokens(revoked) | token 鉴权查询 |
| idx_messages_conversation | messages(conversation_id) | 按会话查消息 |

向量检索无需索引（全表 numpy 扫描）；若切片量超万级，替换向量库（R108）或引入 FAISS（评估中）。

---

## 四、数据生命周期

- 上传：`uploads/<doc_id>/<净化文件名>` 落盘（源文件保留，供 Web 预览）→ documents 插入（parsing）→ 解析管线 → chunks 批量插入 → documents 置 ready/failed。
- 删除：事务内删除 chunks + documents + 磁盘目录（uploads/<doc_id>/）。
- 备份/迁移（R115 前基础）：整体拷贝 `data/` 目录（rag.db + uploads 一致即完整）。
