## 二、管理员安装项（winget 命令，由用户手工执行）

以下命令**需要管理员权限**或系统级安装，按提示执行：

```powershell
# 1. Python（如目标机器未安装；本机已装 3.14.7 可跳过）
winget install --id Python.Python.3.14 -e --scope machine

# 2. Ollama（本地 AI 后端，演示推荐；装后无需管理员）
winget install --id Ollama.Ollama -e          # 若提示权限，加 --scope machine
```

Ollama 安装完成后拉取模型（普通权限，命令窗口执行）：

```powershell
ollama pull qwen2.5:7b     # 问答 / 文字处理
ollama pull bge-m3         # embedding（1024 维）
ollama pull llava:7b       # 图片理解 / OCR（可选，或 qwen2.5vl:7b）
```

> 云端模式无需安装任何软件：在设置页填 OpenAI 兼容 base_url + API Key 即可（DeepSeek 无 embedding 接口，embedding 需 OpenAI/通义等或本地 bge-m3）。

## 四、环境验证命令

```powershell
# 后端
python --version                    # 3.14.7
cd backend
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install -r requirements.txt
python -c "import fastapi, uvicorn, numpy, pypdf, docx; print('deps OK')"

# 启动
python -m uvicorn app.main:app --port 8000
# 浏览器打开 http://127.0.0.1:8000

# Ollama（如安装）
ollama list                          # 确认模型已拉取
curl http://127.0.0.1:11434/v1/models
```

### PyPI 网络不稳定处理

本机访问 pypi.org 偶发超时；安装失败时重试，或使用镜像：

```powershell
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
```

## 五、版本管理规则

1. **版本号**：应用首个版本 `0.1.1`；每次变更第三段 +1（0.1.1 → 0.1.2 → …）；重大变更升第二段（0.2.0）。同步更新 `config.py` 的 `APP_VERSION`、README、release 目录名。
2. **依赖锁定**：`backend/requirements.txt`（运行时）与 `build-requirements.txt`（+ pyinstaller）提交仓库；不提交 venv 与 `data/`。
3. **发布物**：`release/lantai-0.1.x-windows-x64/`（PyInstaller one-dir）+ zip；无 setup 安装包。
4. **编码**：所有文件读写显式 UTF-8（规避 Windows GBK）。
5. **变更记录**：需求/方案变更记入 `docs/04-风控管理/需求变更记录.md`（预留，首版暂不建）。
