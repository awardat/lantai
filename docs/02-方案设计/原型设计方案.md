## 一、设计概述

### 1.1 设计目标

- **业务功能为首页**：打开即用（问答、文档管理两个 Tab），零学习成本；
- **配置功能收口**：右上角设置图标进入，密码门禁（默认 `Admin#123`），与业务隔离；
- 问答结果"可溯源"：相似度分数 + 引用来源 + Web 内源文件预览；
- 全中文界面与错误提示，适合现场演示。

### 1.2 信息架构

```
兰台（单页应用）
├── 业务功能（首页，免登录）
│   ├── Tab 1 问答
│   │   ├── 问题输入框（提问按钮）
│   │   ├── 答案区（纯文本渲染；Markdown 渲染列入后续迭代）
│   │   └── 来源卡片列表（文档名 / 相似度 / 切片摘要 / 预览源文件按钮）
│   └── Tab 2 文档管理
│       ├── 上传按钮（多选文件）
│       ├── 状态提示条（上传中/解析中）
│       └── 文档列表（名称/类型/大小/状态/切片数/时间/操作[预览·删除]）
├── 配置功能（设置图标 → 密码门禁 → 进入）
│   ├── AI 配置（默认 Tab）
│   │   ├── 五类文件处理 AI 卡片（文字文档/Office/文字PDF/图片/图片PDF·OCR）
│   │   │   └── 每卡：Provider 下拉 / Base URL / API Key（脱敏）/ 模型 / 提示词 / 测试连接
│   │   └── 全局：问答模型 / Embedding 模型（同结构）
│   ├── API Token（生成表单[名称] / 列表[名称·前缀·时间·吊销] / 明文一次性展示）
│   ├── 修改密码（旧密码 / 新密码 / 确认新密码）
│   └── 关于（版本 0.1.1、平台、数据目录）
└── 预览浮层（业务内弹出，展示源文件内容）
```

### 1.3 核心交互

- **上传**：选择文件 → 上传 → 列表出现"解析中" → 轮询/刷新后"已就绪"；失败显示原因与重传入口。
- **问答**：输入问题 → 回车/按钮 → 答案区流式渲染（首版非流式，档位 3 SSE）→ 来源卡片展示相似度。
- **预览**：点击"预览源文件" → 浮层展示（txt/md/docx/pdf 提取文本；图片原样显示；扫描 PDF 页提示"本页为图片"）。
- **配置**：点设置图标 → 弹密码框 → 校验通过（Cookie 会话）→ 进入配置区；未验证直接调用配置 API 返回 401 并弹密码框。

## 二、页面规格

### 2.1 业务首页

| 区域 | 元素 | 说明 |
|------|------|------|
| 顶栏 | 品牌"兰台"、Tab（问答/文档管理）、**设置图标**（右上角） | 设置图标为配置功能唯一入口 |
| 问答 Tab | 问题输入框（占位"请输入问题，如：什么是兰台？"）、提问按钮；答案区；来源卡片 | 来源卡片含文档名、相似度分数（如 0.8731）、切片文本摘要、"预览源文件"按钮 |
| 文档管理 Tab | 上传按钮；文档列表表格；删除确认弹窗 | 状态徽标：解析中（蓝）/ 已就绪（绿）/ 失败（红+原因） |

### 2.2 配置功能（密码门禁后）

| 区域 | 元素 | 说明 |
|------|------|------|
| 密码门禁 | 密码输入框 + 确认按钮；错误提示 | 默认 `Admin#123`；连续 5 次错误锁定 1 分钟 |
| AI 配置 | 7 组配置卡片（五类文件 + 问答 + embedding）；每卡：Provider 下拉（ollama/openai-compatible）、Base URL、API Key（占位"已保存 ****abcd"，留空=不变）、模型名、提示词（图片/OCR 类）、温度、测试连接按钮 | 保存即时生效；测试连接回显模型列表或中文错误 |
| API Token | 生成区（名称输入 + 生成按钮）；生成后弹窗展示明文（仅一次，提示复制）；列表（名称/前缀/创建时间/最后使用/操作：吊销） | 吊销二次确认 |
| 修改密码 | 旧密码 / 新密码 / 确认新密码 / 提交 | 新密码 ≥8 位；成功提示后需重新验证 |
| 关于 | 版本号、平台、数据目录路径 | 只读 |

### 2.3 预览浮层

| 类型 | 渲染 |
|------|------|
| txt / md | 原文（等宽字体），md 不做渲染保持原文 |
| docx | python-docx 提取的段落与表格文本 |
| pdf（文字） | pypdf 提取文本（按页分节） |
| pdf（图片/扫描） | 提示"本页为图片内容，未 OCR 识别"，并展示页内图片（若可提取） |
| 图片 | `<img>` 原图直出（preview/raw 接口） |

## 三、状态与异常展示

| 场景 | 展示 |
|------|------|
| Ollama 未启动 | toast："无法连接 Ollama（127.0.0.1:11434），请确认已启动或改配云端 API" |
| 模型未拉取 | 文档状态失败/问答错误："模型 qwen2.5:7b 不存在，请执行 ollama pull qwen2.5:7b 或修改配置" |
| API Key 无效 | toast："鉴权失败（401），请检查 API Key" |
| 文件类型不支持 | 上传前校验并提示白名单 |
| 超过 20MB | 上传前校验并提示 |
| 知识库为空 | 答案区提示"知识库暂无内容，请先在文档管理上传文档" |
| 无检索命中 | 答案区提示"未检索到相关内容，请换一种问法或补充文档" |
