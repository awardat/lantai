## 一、设计概述

### 1.1 设计目标

- **业务功能为首页**：打开即用（问答、文档管理两个 Tab），零学习成本；
- **配置功能收口**：右上角设置图标进入，密码门禁（默认 `Admin#123`），与业务隔离；
- 问答结果"可溯源"：相似度分数 + 引用来源 + Web 内源文件预览；
- 全中文界面与错误提示，适合现场演示。

### 1.2 信息架构（0.1.8 起：左右两栏）

```
兰台（单页应用，左右两栏）
├── 左栏（固定宽度 260px）
│   ├── 顶部品牌：logo 方块"兰" + 品牌文字"蘭臺" + 副标题
│   ├── 会话历史列表（首轮问答自动命名；标题超宽截断、悬停显示全文；
│   │   行内 ✎ 改名 / 🗑 删除小图标；点击切换会话，恢复历史消息）
│   └── 底部导航：问答 / 文件管理 / 设置
└── 右栏（自适应）
    ├── 问答视图：消息流（用户/助手气泡，引用来源以更小字体夹在答案下方，可点预览）
    │   ＋ 底部输入框（Enter 发送，提问后自动清空；未选会话时自动创建并命名）
    ├── 文档管理视图：上传按钮、文档列表（名称/类型/大小/状态/切片数/时间/操作[预览·删除]）
    └── 配置浮层（设置入口 → 密码门禁小窗口 → 大窗口配置）
        ├── AI 配置（供应商下拉自动填充 URL/推荐模型；测试连接展示模型清单可点击填入；
        │   输入框焦点离开自动保存；五类文件 + 问答 + embedding 七组卡片）
        ├── API Token（生成[名称] / 列表[前缀·时间·吊销] / 明文一次性展示）
        ├── 修改密码（旧 / 新 / 确认）
        └── 关于（版本号、平台、数据目录）
```

### 1.3 核心交互

- **上传**：选择文件 → 上传 → 列表出现"解析中" → 轮询/刷新后"已就绪"；失败显示原因与重传入口。
- **问答**：输入问题 → 回车/按钮 → 答案 **SSE 流式**渲染（0.1.5 起）→ 引用来源小字内嵌于答案下方（0.1.8 起）。
- **预览**：点击"预览源文件" → 浮层展示（txt/md/docx 文本；图片原样；**PDF 浏览器原生渲染**（0.1.9/0.1.13），扫描件/编码不可映射 PDF 附原因提示）。
- **配置**：左栏底部设置入口 → 弹密码框（小窗口）→ 校验通过（Cookie 会话）→ 进入大窗口配置区；AI 配置修改后焦点离开自动保存（0.1.7 起）。

## 二、页面规格

### 2.1 业务首页

| 区域 | 元素 | 说明 |
|------|------|------|
| 左栏 | 品牌（logo + "蘭臺"）、会话历史列表、底部导航（问答/文件管理/设置） | 固定宽度 260px；设置入口在底部导航 |
| 问答视图 | 消息流 + 底部输入框（Enter 发送、提问后清空）；来源小字内嵌答案下方 | 来源行：文档名 · 相似度（如 0.8731）· 预览链接 |
| 文档管理视图 | 上传按钮；文档列表表格；删除确认弹窗 | 状态徽标：解析中（蓝）/ 已就绪（绿）/ 失败（红+原因） |

### 2.2 配置功能（密码门禁后）

| 区域 | 元素 | 说明 |
|------|------|------|
| 密码门禁 | 密码输入框 + 确认按钮；错误提示 | 默认 `Admin#123`；连续 5 次错误锁定 1 分钟 |
| AI 配置 | 7 组配置卡片（五类文件 + 问答 + embedding）；每卡：Provider 下拉（ollama/openai-compatible）、Base URL、API Key（占位"已保存 ****abcd"，留空=不变）、模型名、提示词（图片/OCR 类）、温度、测试连接按钮 | 保存即时生效；测试连接回显模型列表或中文错误 |
| API Token | 生成区（名称输入 + 生成按钮）；生成后弹窗展示明文（仅一次，提示复制）；列表（名称/前缀/创建时间/最后使用/操作：吊销） | 吊销二次确认 |
| 修改密码 | 旧密码 / 新密码 / 确认新密码 / 提交 | 新密码 ≥8 位；成功提示后需重新验证 |
| 关于 | 版本号、平台、数据目录路径 | 只读 |

### 2.3 预览浮层

| 类型 | 渲染 |
|------|------|
| txt / md | 原文（等宽字体），md 不做渲染保持原文 |
| docx | python-docx 提取的段落与表格文本 |
| pdf（文字） | pypdf 提取文本（按页分节） |
| pdf（图片/扫描） | 提示"本页为图片内容，未 OCR 识别"，并展示页内图片（若可提取） |
| 图片 | `<img>` 原图直出（preview/raw 接口） |

## 三、状态与异常展示

| 场景 | 展示 |
|------|------|
| Ollama 未启动 | toast："无法连接 Ollama（127.0.0.1:11434），请确认已启动或改配云端 API" |
| 模型未拉取 | 文档状态失败/问答错误："模型 qwen2.5:7b 不存在，请执行 ollama pull qwen2.5:7b 或修改配置" |
| API Key 无效 | toast："鉴权失败（401），请检查 API Key" |
| 文件类型不支持 | 上传前校验并提示白名单 |
| 超过 20MB | 上传前校验并提示 |
| 知识库为空 | 答案区提示"知识库暂无内容，请先在文档管理上传文档" |
| 无检索命中 | 答案区提示"未检索到相关内容，请换一种问法或补充文档" |
