## 一、产品概述

### 1.1 背景

个人与团队的资料散落在 txt/md/pdf/docx/图片 中，检索靠记忆、问答靠人工。主流 RAG 方案依赖云端、数据外流、部署复杂。兰台定位**本地运行、两步启动、浏览器即用**的 RAG 知识库演示产品：文档入库后，以自然语言提问即可获得带引用的答案，全程数据留在本机。

### 1.2 产品定位

本地单机 RAG 知识库演示产品：**FastAPI 后端（纯 API）+ 原生 Web 前端（无构建步骤）**，单机部署（win+x64），双 AI Provider（Ollama 本地 / OpenAI 兼容云端）按文件类型可混配。

- **业务功能为首页**：问答、文档管理两个 Tab；
- **配置功能**：右上角设置图标进入，密码门禁（默认 `Admin#123`，可修改）：AI 配置、API token、修改密码、关于。

### 1.3 核心价值

| 价值点 | 说明 | 对应指标（来源：需求池管理表.md） |
|--------|------|----------|
| 数据不出门 | 本地向量库 + 可选本地 Ollama，全链路数据在机内 | 无任何外部数据上传（除用户主动配置的云端 AI 调用） |
| 即传即问 | 上传→解析→入库自动化，问答秒级返回 | 上传解析 ≤1 分钟（20MB 内演示文档）；检索 <500ms（R005） |
| 有据可查 | 答案带引用来源 + 相似度分数 + 源文件预览 | 引用来源 100% 展示（R006/R007） |
| 按类配 AI | 图片/OCR/Office/文字 PDF 等五类文件各自配模型 | 五类文件均产出可检索文本（R002/R008） |
| 轻量易用 | 无构建、无 setup、目录级部署 | 编译版解压即用（R015/R016） |

> 来源：需求池管理表.md（R001-R016）

## 二、目标用户

### 2.1 用户画像与权限模型

**首版（v0.1.1）**：单管理员模式——业务功能免登录使用；配置功能由密码门禁保护（默认 `Admin#123`，可修改）；外部程序调用通过 API token（R011）。

**RBAC 设计（R101，本期不实现，仅设计）**：

| 角色 | 业务功能 | 配置功能 | 说明 |
|------|----------|----------|------|
| 管理员 | 全部 | 全部（AI 配置 / token / 改密） | 未来由密码门禁迁移而来 |
| 普通用户 | 问答、文档管理（按文档可见范围） | 无 | 需登录（R113） |
| API 调用方 | 通过 token 调 `/api/chat` 等 | 无 | 现版本已支持 |

权限点（设计）：`doc.upload / doc.delete / doc.read`、`chat.ask`、`settings.read / settings.write`、`token.manage`、`password.change`。后端强制校验，不依赖前端隐藏。

> 来源：需求池管理表.md（R101、R113）

### 2.2 使用场景

| 场景 | 触发时机 | 涉及角色 | 说明 |
|------|----------|----------|------|
| 文档入库 | 首次使用 / 资料更新 | 管理员/用户 | 上传 → 按类型解析 → 切块 → 向量化（R001-R003） |
| 知识问答 | 日常查询 | 用户 | 提问 → top-k 检索 → AI 生成带引用答案（R005-R006） |
| 溯源核对 | 对答案存疑时 | 用户 | 点击来源卡片预览源文件核对（R007） |
| 调整模型 | 换模型/换 Provider 时 | 管理员 | 设置页按文件类型配置，即时生效（R008-R009） |
| 外部调用 | 程序集成时 | 管理员 | 生成 API token 调问答接口（R011） |

## 三、功能需求

> 功能均来自需求池管理表.md，优先级均为 P0（v0.1.1）。

### 功能一：文档管理（上传 / 解析 / 列表 / 删除）

**优先级**: P0 ｜ **来源**: 需求池 R001、R002、R003、R004

**3.1.1 功能描述**

文档管理 Tab：上传文件（多选，≤20MB，白名单 `txt md pdf docx png jpg jpeg webp bmp gif`），上传后异步执行解析管线（按文件类型路由 → 文本提取 → 切块 → 向量化入库），列表展示状态，可删除。

**3.1.2 业务规则**

1. 解析管线按类型路由（详见技术对接方案 §4）：文字文档直接读文本；Office（docx）python-docx 提取；文字 PDF pypdf 提取文本层；**图片**调用该类型配置的视觉模型生成内容描述；**图片 PDF**（无文本层）逐页走 OCR 模型。
2. 切块默认 400 字符/块、重叠 50 字符、段落感知；逐块调用全局 embedding 模型。
3. 文档状态机：`解析中 → 已就绪 / 失败`；失败记录中文原因，可删除重传。
4. 删除级联：文档记录、全部切片向量、上传源文件一并删除。

**3.1.3 边界条件**

- 类型限制：白名单外扩展名拒绝（R001 验收标准）。
- 大小限制：单文件 ≤20MB。
- 同名文件：允许重复上传，各自独立。

**3.1.4 异常处理**

- 解析失败：状态置"失败"并提示原因（如"模型未拉取，请执行 ollama pull llava:7b"），不影响其他文档。
- 上传中断/超限：前端拦截并中文提示。

**3.1.5 验收标准**

- 五类文件均能完成"上传→已就绪"，切片数正确（R003）。
- 删除后文档/切片/源文件均不可检索、不可预览（R004）。
- 解析失败提示包含解决建议（R013）。

---

### 功能二：知识问答与检索（top-k + 相似度 + 引用 + 预览）

**优先级**: P0 ｜ **来源**: 需求池 R005、R006、R007

**3.2.1 功能描述**

问答 Tab：输入问题 → 问题向量化 → numpy 余弦检索 top-k 切片（默认 5）→ 拼接上下文调用全局问答模型生成答案。页面展示：答案正文、引用来源卡片（文档名、切片文本、相似度分数、"预览源文件"按钮）。

**3.2.2 业务规则**

1. 检索：`score = cos(question_vec, chunk_vec)`，降序取 top-k，分数保留 4 位（0~1）。
2. 上下文组装：按分数降序拼接切片文本，附切片元信息（文档名/位置）；系统提示词要求"仅依据给定上下文回答，无法回答时明确说明，不编造"。
3. 来源卡片：每个命中切片一张，含相似度分数；点击"预览源文件"在 Web 内打开该文档预览。
4. 预览接口按类型渲染：txt/md 原文、docx 提取文本、PDF 文本层（扫描页提示"本页为图片"或展示原图）、图片直接显示。
5. 问答模型未配置/不可达：返回 502 类中文错误（"问答模型连接失败：请检查设置页 AI 配置"），前端提示引导。

**3.2.3 边界条件**

- 知识库为空或检索无命中：提示"知识库中暂无相关内容，请先上传文档"。
- top_k 参数：前端固定默认 5，API 可传（1~20）。

**3.2.4 异常处理**

- embedding 失败：提示模型未配置/未拉取的具体建议（R013）。
- 问答超时：设置请求超时（默认 120s），超时中文提示。

**3.2.5 验收标准**

- 检索响应 <500ms（演示规模）；分数降序展示（R005）。
- 答案附带来源，可预览源文件（R006/R007）。
- 无上下文时模型不编造（R006 验收标准）。

### 功能三：按文件类型配置不同 AI

**优先级**: P0 ｜ **来源**: 需求池 R008、R009

**3.3.1 功能描述**

设置页「AI 配置」：**五类文件处理 AI**（文字文档 / Office 文档 / 文字 PDF / 图片 / 图片 PDF·OCR）各自配置 `Provider + Base URL + API Key + 模型名 + 提示词`；**全局问答模型**与**全局 embedding 模型**；每项支持"测试连接"。

**3.3.2 业务规则**

1. Provider 二选一：`ollama`（默认 `http://127.0.0.1:11434`，无 Key）／`openai-compatible`（任意 OpenAI 兼容 base_url + Key）。协议统一 OpenAI 兼容（chat completions / embeddings），Ollama 走其 `/v1` 兼容端点。
2. 默认值（首次启动）：文字/Office/PDF→Ollama `qwen2.5:7b`；图片/OCR→Ollama `llava:7b`；问答→`qwen2.5:7b`；embedding→`bge-m3`。图片类提示词默认"请描述这张图片的内容，包括文字与版式"。
3. 配置保存即时生效；解析与问答按保存时的最新配置执行。
4. API Key 加密存储于 settings 表（见数据库设计文档），接口返回时脱敏（只显示尾 4 位）。
5. "测试连接"：调用 `GET {base}/models` 并回显模型列表；失败给出具体原因（连接拒绝 / 401 / 404 等）。

**3.3.3 边界条件**

- 未配置项：使用默认值；默认 Provider（Ollama）不可达时，相关功能报中文错误并引导（R013）。
- DeepSeek 官方 API 无 embeddings 接口：配置页对 embedding 项提示"请选支持 embeddings 的服务或本地 bge-m3"。

**3.3.4 异常处理**

- 模型不存在：解析/问答失败时提示"模型 X 不存在，请先 ollama pull X 或修改配置"。

**3.3.5 验收标准**

- 修改某一类型模型后，重新上传该类型文档按新模型解析（R008）。
- Ollama 与云端可混配（如图片走云端视觉模型、文字走本地）。
- 测试连接可列出模型或给出准确失败原因（R009）。

### 功能四：配置功能与安全（密码门禁 / API token / 修改密码）

**优先级**: P0 ｜ **来源**: 需求池 R010、R011、R012

**4.1.1 功能描述**

- **密码门禁**：业务首页右上角设置图标 → 进入配置前弹出密码输入（默认 `Admin#123`）；校验通过发短时会话（HTTP-only Cookie，默认 24h）。
- **API token**：设置页生成（命名、前缀 `lt-`、明文仅展示一次）、列表（脱敏）、吊销；用于外部调用 `POST /api/chat`（`Authorization: Bearer <token>`）。
- **修改密码**：旧密码 + 新密码（≥8 位）两次确认。

**4.1.2 业务规则**

1. 密码 PBKDF2-HMAC-SHA256（10 万次迭代 + 随机盐）哈希存储于 settings 表；首次启动写入默认密码哈希。
2. 会话：服务端内存会话表 + 随机 token 的 HTTP-only Cookie；修改密码后旧会话失效。
3. API token：服务端存 SHA-256 哈希与名称/前缀/创建时间/最后使用时间；吊销即删哈希；调用鉴权先查 Bearer token 再查会话。
4. 业务接口（文档上传/问答）免登录（单用户演示）；配置接口必须会话有效（除密码校验接口本身）。

**4.1.3 边界条件**

- 密码错误：不区分"用户不存在"，统一提示"配置密码错误"；连续 5 次错误锁定 1 分钟（防爆破）。
- token 明文仅展示一次，刷新页面后不可再见。

**4.1.4 异常处理**

- 忘记密码：删除 `data/` 下数据库或重置 settings（README 常见问题给出方法）。

**4.1.5 验收标准**

- 未验证无法进入配置页/调用配置 API（R010）。
- token 可调用问答接口、吊销即失效、列表无明文（R011）。
- 改密后旧密码与旧会话失效（R012）。

## 四、非功能需求

### 4.1 性能

| 指标 | 要求 | 来源 |
|------|------|------|
| 上传解析（20MB 内演示文档） | ≤1 分钟 | 需求池 R001-R003 |
| 检索响应（几十~几百切片） | <500ms | R005 |
| 问答响应 | 依模型而定，超时 120s 提示 | R006 |
| 并发 | 单用户演示，无并发要求 | — |

### 4.2 安全

- 配置密码 PBKDF2 加盐哈希；错误锁定（R010/R012）。
- API token SHA-256 存储；吊销即时生效（R011）。
- 上传安全：扩展名白名单 + 大小限制 + 文件名净化（防路径穿越），存储目录不可执行（R001）。
- 预览与下载鉴权：源文件仅通过预览接口按文档 ID 读取，禁止目录遍历（R007）。
- 会话 Cookie：HTTP-only、SameSite=Lax（R010）。

### 4.3 可用性

- 全部失败场景中文提示 + 解决建议（R013）。
- 数据目录独立（`data/`），整体拷贝即备份迁移（R115 前的基础）。
- 无需 GPU/分布式，演示规模毫秒级检索。

### 4.4 兼容性

- 浏览器：Chrome / Edge 最新版（前端原生 JS，无构建）。
- Python 3.14.7（已验证依赖兼容）；避免 torch/chromadb/onnxruntime。
- Windows 10/11 x64；Linux/arm64 仅需求（R102）。

## 五、交互流程

### 5.1 核心用户旅程

```
首次使用：打开 http://127.0.0.1:8000
  → 业务首页（问答/文档管理）
  → 文档管理：上传文件 → 状态"解析中" → "已就绪"
  → 问答：输入问题 → 检索 top-k（相似度分数）→ AI 生成答案 + 引用来源
  → 点击来源"预览源文件"：Web 内查看（txt/md/docx/pdf/图片）
配置路径：业务首页右上角设置图标 → 输入密码（默认 Admin#123）
  → AI 配置（五类文件 + 问答 + embedding）／ API token ／ 修改密码 ／ 关于
外部调用：生成 API token → POST /api/chat {question} + Bearer token
```

### 5.2 关键页面

| 页面 | 归属功能 | 核心元素 |
|------|----------|----------|
| 业务首页·问答 | 功能二 | 问题输入框、答案区、来源卡片（文档名/相似度/预览按钮） |
| 业务首页·文档管理 | 功能一 | 上传按钮、文档列表（名称/类型/大小/状态/切片数/时间/删除） |
| 配置·AI 配置 | 功能三 | 五类文件配置卡片、问答/embedding 全局配置、测试连接 |
| 配置·API Token | 功能四 | 生成表单、token 列表（脱敏）、吊销按钮 |
| 配置·修改密码 | 功能四 | 旧密码、新密码、确认新密码 |
| 配置·关于 | 功能五 | 版本号、平台、数据目录 |

## 七、里程碑与依赖

