## 版本列表

| 版本 | 日期 | 类型 | 修改内容 |

| **0.1.1** | 2026-08-23 | 首个版本 | 文档体系（需求池/PRD/技术对接/数据库设计/原型设计/开发环境/API说明）+ 可运行原型：前后端分离、五类文件按类型 AI 配置、配置密码门禁（Admin#123）、API token、源文件 Web 预览、SQLite+numpy 向量检索、中文错误提示；`release/lantai-0.1.1-windows-x64/` 编译版 |
| **0.1.2** | 2026-08-23 | 缺陷修复 | 按评审报告（docs/05-质量评审/代码与文档评审报告-v0.1.1.md）修复：S1 API Key 未解密、H1 async 端点阻塞事件循环、M1 配置部分提交覆盖、M2/M3 构建 spec 入库、L1-L9 文档与代码同步（索引/ai_key_salt/XOR 描述/接口路径/Markdown 渲染/导入目录/建表开销/on_event 废弃/向量维度保护）、temperature clamp 与 provider 白名单 |
| **0.1.3** | 2026-08-23 | 新增功能 | AI 供应商预置（7 个供应商：Ollama/DeepSeek/通义/智谱/Kimi/硅基流动/OpenAI，预置 URL 与推荐模型，国产优先）、AI 配置界面固定尺寸与滚动条、需求变更记录文档（docs/04-风控管理/）、README 模型推荐表 |
| **0.1.4** | 2026-08-23 | 新增功能 | 供应商新增 OpenCode Go（本地代理 http://127.0.0.1:8787/v1）、DeepSeek 默认模型改为 deepseek-v4-flash、「测试」功能（测试连通性并获取模型清单，点击模型名自动填入）、后端日志文件输出（data/logs/，每次启动新文件，保留 20 个）、503 错误提示通用化（本地服务未就绪） |
| 0.1.4（修订） | 2026-08-23 | 修订 | 配置窗口尺寸调整：进入配置功能后为大窗口（宽 880px / 高 86vh 封顶 920px，尺寸固定不随展开变化、内部滚动）；**密码门禁界面为小窗口（宽 460px、高度自适应内容，无留白）**；新建本版本记录文件（版本号与修改内容不放入 README，README 改为引用本文件）。（并入 0.1.4，不另升版本） |
| **0.1.5** | 2026-08-23 | 新增功能 | 档位 3 首批：**流式输出（SSE）**——`POST /api/chat/stream`（sources → delta → done 事件，前端打字机渲染）；**对话历史**——conversations/messages 表（schema v2）、会话创建/列表/删除/消息查询接口、提问自动携带最近 6 条历史消息作为上下文并入库；前端会话管理（新建/切换/删除/历史渲染，未选会话时提问自动创建）；新增 `scripts/mock_ai_server.py` 开发自测 Mock AI 服务 |
