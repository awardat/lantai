## 一、测试环境准备

### 1.1 环境
| 项 | 要求 |
|----|------|
| 系统 | Windows 10/11 x64，浏览器 Chrome/Edge 最新 |
| 运行方式 | 二选一：源码运行（`cd backend && .\.venv\Scripts\activate && python -m uvicorn app.main:app --port 8000`）或编译版（`release/lantai-0.1.17-windows-x64\lantai.exe`） |
| 访问 | http://127.0.0.1:8000 |

### 1.2 AI 后端（按测试项选择）
| 方式 | 准备 |
|------|------|
| Mock AI（推荐默认） | `python scripts/mock_ai_server.py --port 18000`；设置页将 chat/embedding/文字类指向 `http://127.0.0.1:18000`（模型 mock-chat / mock-embed） |
| Ollama（可选） | 管理员安装 + `ollama pull qwen2.5:7b / bge-m3 / qwen2.5vl:7b` |
| 云端（可选） | 任一供应商 API Key |

### 1.3 测试数据
- `python scripts/make_sample_docs.py` 生成样例（txt/md/docx/pdf/图片）
- 样本目录 `sample/`：扫描件 PDF（`自 2026-06-18 04_10_08 PM 起扫描.pdf`）、Asperger 论文 PDF（56 页文字 PDF）
- 准备一个**超 20MB** 文件与一个 `.exe` 文件（负向用例）
