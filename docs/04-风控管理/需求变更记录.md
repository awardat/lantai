### CH-018: 配置功能自动保存 + OpenCode Go 官方端点

**类型**: 新增需求 ｜ **版本**: 0.1.7 ｜ **来源**: 用户 ｜ **状态**: 已完成

**描述**:
1. **配置自动保存**：AI 配置 Tab 的输入框（Base URL / API Key / 模型 / 提示词 / 温度 / 供应商下拉）**焦点离开（blur/change）即自动保存**，立即生效；保存请求串行化（Promise 链）防止并发读改写竞争；Tab 顶部轻提示"✓ 已自动保存 HH:MM"；保留"立即保存全部"按钮兜底。
